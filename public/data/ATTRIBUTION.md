# Catalog attribution

The list of websites in this dataset is taken from [awesome-vibe-coded-apps](https://github.com/JefferyLee/awesome-vibe-coded-apps), which is released under CC0 1.0. A copy of that legal code is in `CATALOG-CC0.txt`.

Twinsites stores, for each included URL:

- the title and short description published in that catalog
- a viewport screenshot of the public homepage (1440×900), reduced to a small WebP thumbnail
- a visual embedding and a 2D position computed from that screenshot

Screenshots are served only so a visitor can see why two pages were called similar. They are not a mirror of those sites.

To ask for a page to be removed, open a removal request: https://github.com/AnaGuiDev/twinsites/issues/new?template=removal.yml
